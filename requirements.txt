# Fully resolved lock for the Lambda image.
#
# The previous version pinned only the five top-level packages and let every
# transitive dependency float. That image stopped building in 2026: pip resolved
# scikit-learn to a release with no cp311 wheel and fell back to compiling from
# source, which fails because the Lambda base image ships no C compiler.
#
# Everything is pinned here. Regenerate with:
#   docker run --rm --entrypoint /bin/sh <image> \
#     -c "python3 -m pip list --format=freeze --path /var/task" | sort
#
# torch is the CPU build. The default x86 wheel pulls ~2.6 GB of CUDA libraries
# that cannot execute on Lambda; +cpu drops them and takes the image from
# 8.43 GB to 2.66 GB.
#
# The +cpu variant only exists for x86_64. On aarch64 there is no CUDA to strip,
# so the stock PyPI wheel is already CPU-only (and 74 MB rather than 620 MB).
# The markers below pick the right one so this file works for both targets.
